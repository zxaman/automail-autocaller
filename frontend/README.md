# AutoCall & AutoMail Frontend

This directory is reserved for the Angular standalone frontend.

The Angular dependency set has been prepared and installed, but the Angular workspace and feature screens will be created during the frontend foundation phase.

Planned structure:

- `src/app/core`
- `src/app/layout`
- `src/app/shared`
- `src/app/features`

The frontend must communicate with the backend through relative API URLs in browser-facing code. It must not call `localhost` directly from a deployed or mobile browser context.
